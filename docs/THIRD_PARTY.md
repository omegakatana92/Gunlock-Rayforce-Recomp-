|---|---|---|

| SDL2 | window, renderer, audio, controllers | zlib |
| miniz | zip reading, compression of save states | MIT |
| nlohmann/json | settings / profiles | MIT |
| stb_truetype, stb_image | font rendering, wallpapers | public domain / MIT |
| Rajdhani, Press Start 2P fonts | interface typography | SIL OFL 1.1 |
