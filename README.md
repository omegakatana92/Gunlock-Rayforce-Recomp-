# Gunlock / RayForce — Native Recompilation

**Gunlock / RayForce Native Recomp** is a fan-developed native arcade recompilation project dedicated to bringing Taito's classic 1994 vertically scrolling shoot-'em-up to modern Windows, Linux, and Steam Deck systems.

Originally released as *RayForce* in Japan and *Gunlock* in Europe, this arcade shooter is known for its layered scrolling environments, cinematic presentation, lock-on targeting system, and challenging gameplay.

The project aims to preserve the authentic arcade experience while introducing modern PC compatibility and quality-of-life enhancements.

## Project Features and Goals

- **Native Recompilation:** Recompile the original arcade game code for execution on modern PC hardware.
- **RayForce / Gunlock Support:** Preserve the regional identity of both arcade releases.
- **Original Arcade Gameplay:** Maintain the classic shooting mechanics, lock-on laser targeting, enemy behavior, and stage progression.
- **Save States:** Save and restore gameplay progress.
- **Modern Frontend:** User-friendly menus for game configuration and settings.
- **Controller Support:** Configurable keyboard and gamepad controls.
- **Display Options:** Original aspect-ratio preservation, scaling, fullscreen, and vertical display support.
- **Audio Support:** Preserve the original arcade soundtrack and sound effects.
- **Cross-Platform Development:** Target Windows x64, Linux x86-64, and Steam Deck.

## Supported Game Versions

- RayForce — Japanese Arcade Release
- Gunlock — European Arcade Release

Regional compatibility and edition-selection functionality depend on implementation and testing.
